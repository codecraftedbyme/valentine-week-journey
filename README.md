# 💖 Our Love Journey | Interactive Valentine's Week

A beautifully crafted digital experience that celebrates the essence of Valentine's week. This interactive web app takes the user through a romantic journey, starting from a playful interaction to a full week of virtual celebrations.

## ✨ Features
- **Typewriter Intro:** A soft, engaging greeting that types out letter-by-letter.
- **Interactive Love Lock:** A "Do you love me?" screen with a playful "No" button that can't be clicked easily.
- **Valentine Week Stages:** Dedicated screens for Rose Day, Propose Day, Teddy Day, Hug Day, Kiss Day, and the grand Valentine's Day.
- **Floating Heart Animation:** A constant stream of floating 💗 emojis to keep the vibe romantic.
- **Aesthetic Design:** Pastel colors, cursive fonts, and smooth fade-in transitions.
- **Responsive:** Mobile-friendly layout designed for sharing with your favorite person.

## 🛠️ Tech Stack
- **Frontend:** HTML5 & CSS3 (Custom animations & Linear gradients)
- **Logic:** Vanilla JavaScript (DOM manipulation & Interval animations)
- **Typography:** Google Fonts (Dancing Script & Quicksand)
